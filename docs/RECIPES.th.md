# สูตรทำลุค (ภาษาไทย)

ทุกสูตรใช้ได้ในแอปเลย ไม่ต้องเขียนโค้ด เลือกคลิปบน timeline → แท็บ **Inspector** → **Effects chain → Presets…** แล้วปรับพารามิเตอร์ได้ตามชอบ
(`◇` = ใส่ keyframe, `∿` = ผูกกับเสียง/บีต)

## ✨ ทำคลิป TikTok ภาษาไทยด้วยปุ่มเดียว (TikTok Auto-Edit)
1. Import คลิปที่มีเสียงพูด แล้วคลิกเลือกบน timeline
2. กดปุ่ม **✨ TikTok Auto-Edit** บนแถบบน (หรือ `Ctrl/Cmd+Shift+A`)
3. ครั้งแรก: เลือกโมเดลเสียง (แนะนำ **Balanced**) แล้วกด Download (ครั้งเดียว ~540 MB) — ทำงานในเครื่อง ไม่อัปโหลดเสียง
   *ถ้าไม่อยากโหลดโมเดล:* กด "Use a subtitle file (.srt) instead…" แล้วเลือกไฟล์คำบรรยายของคุณ
4. เลือกตัวเลือก: ตัดช่วงเงียบ / ตัด เอ่อ-อืม / ซูมสลับ / เฟรม 9:16 / look / ปรับเสียงให้ดังพอดี −14 LUFS / สไตล์แคปชั่น
5. กด **✨ Run Auto-Edit** → ได้คลิปที่ตัดต่อ ใส่แคปชั่นไทยไฮไลต์ตามคำ จัดเฟรมแนวตั้งแล้ว (ยัง **แก้ต่อบน timeline ได้ทุกอย่าง** และ Undo ได้ในครั้งเดียว)
6. กด **Export for TikTok…** (ตั้ง 1080×1920 คุณภาพสูงให้แล้ว) หรือ **Export captions (.srt)**
- เปิดเส้นกรอบ **▣ Safe zone** ที่แถบเล่นวิดีโอ เพื่อดูว่าส่วนไหนของภาพจะโดนปุ่ม/ข้อความของแอป TikTok บัง
- ถ้าถอดเสียงผิด: ลองโมเดล Balanced/Best, หรือแก้ข้อความแคปชั่นได้ที่แท็บ Inspector ของคลิปข้อความนั้น

## 0. ตั้งค่าโปรเจกต์แนวตั้ง (TikTok / Reels)
- แท็บ **Project** → Canvas = `vertical-1080` (1080×1920) หรือ `vertical-720`
- ถ้านำเข้าวิดีโอแนวตั้งเป็นคลิปแรก แอปจะตั้งขนาดให้เองอัตโนมัติ
- ตอน Export เลือก Preset **"TikTok / Reels / Shorts"** ได้เลย

## 1. ภาพถ่ายเอกสารขาว-ดำ (Xerox) + เม็ด halftone
Preset: **Xerox Photocopy** (คอนทราสต์สูง + toner noise + เกรน) หรือ **Halftone Print (B&W)** (จุด halftone)
- ปรับ `Xerox Threshold → Level` ให้ภาพมืด/สว่างขึ้น, `Toner noise` = ความหยาบ
- เปลี่ยนสีหมึก/กระดาษได้ (`Ink`, `Paper`) เช่นหมึกเขียวเข้ม กระดาษครีม

## 2. โทนสีจัดแบบกราฟิก
- **Comic Flash (red/yellow)**: `Gradient Map` แดง→เหลือง + halftone สีอ่อน ๆ
- **Midnight Purple**: ม่วง/น้ำเงินเข้ม ขอบสีเหลื่อมเล็กน้อย
- ปรับสีเองที่ `Gradient Map → Shadows / Midtones / Highlights`

## 3. สติกเกอร์ขอบขาว (die-cut) และหน้าต่างวงกลม/ก้อน
- Preset **Die-Cut Sticker**: `Shape Mask` (รูปก้อนไม่เท่ากัน) + `Sticker Outline` ขอบขาวหนา
- Preset **Circle Window**: หน้าต่างวงกลมมีขอบ
- ปรับตำแหน่ง/ขนาดที่ `Shape Mask → Position X/Y, Size, Aspect, Rotate, Blob wobble`
- เทคนิค: วางคลิปซ้อนกันหลายแทร็ก แต่ละคลิปมีหน้าต่างคนละรูปทรง = ภาพ collage แบบคลิปอ้างอิงที่ 3
- ใส่ `Solarize / Channel Swap` เพื่อกลับสีนีออน และ `Slices / Cut Bars` เพื่อตัดภาพเป็นแถบดำ

## 4. ตัวอักษรกลวง + glitch
- แท็บซ้าย **02 Type** → preset **Hollow Glitch Block** (ตัวกลวง, เส้นขอบบาง, RGB split, แถบเลื่อน)
- `Fit width` ทำให้ตัวอักษรเต็มความกว้างเฟรมพอดี ไม่ล้นในแนวตั้ง
- โหมดผสม (Blend) = `exclusion` ทำให้ตัวอักษรกลับสีตามภาพข้างหลัง
- แอนิเมชัน `Stutter` ให้ตัวอักษรกระตุกเข้า, `Slam` ให้ทุบเข้ามา

## 5. เส้นขีดเขียนมือ + ฝุ่น/รอยขีดข่วน
- แท็บซ้าย **03 Organic** → **Scribble Contour (hand-drawn)**: เส้นไหวเหมือนวาดมือ (`Hand-drawn boil (fps)`)
- **Dust & Scratches (overlay)**: ฝุ่น/รอยขีดข่วนฟิล์ม วางทับด้วย blend `screen`
- **Root Growth (overlay)**: รากงอกจากด้านล่างทับวิดีโอ (ปรับ `Growth` ด้วย keyframe)

## 6. ตัดตามจังหวะเพลง
1. Import เพลงและวิดีโอ/ภาพ แล้วลากเพลงลงแทร็กเสียง
2. แท็บ **Audio-Reactive** → **Analyze project audio** (จะเห็นขีดบีตบนไม้บรรทัด timeline)
3. เลือกคลิป → ปุ่ม **♪ Cut on beats** (ตัดทุก N บีต) — Undo ได้
4. หรือกด **Auto-montage**: โปรแกรมวิเคราะห์ทั้งเพลง (ช่วงสงบ / ช่วงเต็ม / จุด drop) และทุกคลิป (คมชัด แสง ภาพสั่น การเคลื่อนไหว จุดตัดฉาก) แล้วเลือกช็อตที่ดีที่สุดมาตัดให้ตรงบีต
   - เลือกสไตล์: Hype / Street / Cinematic / Clean และปรับ Cut rate (สงบ ↔ รัว)
   - ช่วงเพลงสงบ = ช็อตยาว, ช่วงเต็ม = ตัดรัว, จุด drop = ช็อตเด่น (hero) ตรงจังหวะพอดี
   - คลิปแนวนอนใส่แคนวาส 9:16 จะครอปตามจุดที่มีการเคลื่อนไหว ไม่ใช่กึ่งกลางภาพ
   - กด **Re-roll** เพื่อลองชุดช็อตอื่นจากการวิเคราะห์เดิม, **Undo** ย้อนทั้งหมดในครั้งเดียว
   - ข้อจำกัด: ไม่ได้ "เข้าใจ" เนื้อหา (จำหน้า/วัตถุ/อารมณ์ไม่ได้) เลือกจากคุณภาพภาพ การเคลื่อนไหว และความเข้ากับเพลง
5. ผูกพารามิเตอร์กับบีต: กด `∿` ข้างค่านั้น → เลือก `beat` เช่น preset **Beat Punch** (กล้องกระชากตามกลอง)

## 7. ความเร็วและเฟด
- Inspector → `Speed` (0.1–4×, เสียงไม่เพี้ยน) ใช้ทำสโลว์/เร่งความเร็ว
- `Fade in / Fade out` ทำภาพและเสียงจางเข้า-ออก

## คีย์ลัด
`Space` เล่น/หยุด · `S` ตัดที่ playhead · `Delete` ลบ · `←/→` ถอย/เดินหน้า 1 เฟรม · `+/-` ซูม timeline
`Ctrl/Cmd+Z` Undo · `Ctrl/Cmd+D` Duplicate · `Ctrl/Cmd+C/V` คัดลอก/วางคลิป · `Ctrl/Cmd+S` บันทึก · `Ctrl/Cmd+E` Export

## แก้คำบนซับไตเติล (Captions)
1. หลังรัน Auto-Edit กด **Edit captions…** (หรือปุ่ม **Captions** ที่แถบบน)
2. แก้คำที่ผิดในแต่ละบรรทัด — จังหวะไฮไลต์ของคำที่เหลือยังอยู่ที่เดิม, กด Apply แล้ว Undo ครั้งเดียวย้อนได้
3. ติ๊ก "Remember the corrections" ไว้ โปรแกรมจะจำคำที่คุณแก้ (เช่น ติ๊กต๊อก → TikTok) และแก้ให้อัตโนมัติในครั้งต่อไป พร้อมส่งเป็นคำใบ้ให้ Whisper
4. ช่อง Vocabulary แก้เองได้ บรรทัดละคู่: `คำที่ฟังผิด → คำที่ถูก`
5. ถ้ายังไม่แม่น ลองโมเดล **Maximum (large-v3)** และเปิด "Clean the audio before transcribing"

## ไตเติลสคริปต์ + Cross-dissolve (สไตล์ editorial)
1. แท็บ **Type** → กด **Title lockup**: ได้คลิปข้อความ 2 คลิป ตัวเล็กแบบเซอริฟ (kicker) อยู่เหนือชื่อเรื่องตัวเขียนสีชมพู (ฟอนต์ Pinyon Script ติดมากับแอป) แก้ข้อความ/สี/ฟอนต์ได้ใน Inspector
2. วางไตเติลทับช็อตเปิด (วิวถนน/ตึก) แล้วต่อด้วยช็อตคนพูด
3. เลือกคลิปที่ต้องการให้ "จางเข้า" แล้วกดปุ่ม **Dissolve** (เลือกความยาว 0.25–1.5 วินาที) — คลิปจะซ้อนทับท้ายคลิปก่อนหน้าและผสมภาพกันจริง Undo ได้ครั้งเดียว
4. ใช้ซ้ำกับคลิปถัดไปได้ ระบบสลับแทร็กให้เอง (คลิปบนจะจางเข้า/จางออกทับคลิปล่าง)

## สายนิช / Y2K (v0.2.1)
1. **ตัวอักษร**: แท็บ **Type** → ลองพรีเซ็ต *Y2K Chrome Bubble*, *Tokyo Vertical* (แนวตั้งญี่ปุ่น), *Cyber Katakana*, *Digicam Date Stamp*, *REC Overlay* หรือปุ่ม lockup ใต้ Title lockup (Y2K × 日本語, Gothic × 明朝, Techno spec). ติ๊ก **Vertical** ใน Inspector เพื่อเขียนแนวตั้งกับข้อความอะไรก็ได้
2. **เกรดทั้งเฟรม**: แท็บ **Looks** → กดลุคเดียวได้ *Adjustment layer* (เลเยอร์ที่ไม่มีภาพ แต่เอฟเฟกต์ของมันครอบทุกอย่างที่อยู่ใต้มัน) ลากขอบบน timeline เพื่อครอบเฉพาะช่วง ลด Opacity เพื่อผสม — ลอง *Digicam 2002*, *Chrome Haze*, *Glints*
3. **Organic ที่ฝังอยู่ในภาพ**: แท็บ **Organic** → *Veins · Overgrown / Glass / Negative / Burnt Channels / Chrome Nerves / Beat Pulse* เส้นจะงอกจากขอบ/ด้านบน/ตรงกลาง รับแสงและบิดภาพจากฟุตเทจเอง (ปรับ Growth, Density, Thickness, Grows from ในเอฟเฟกต์ *Veins*)
4. **Auto-montage**: เลือกสไตล์ *Y2K* หรือ *Organic*; กด ★ ที่คลิปใน Library เพื่อให้ใช้บ่อยขึ้น หรือ ⊘ เพื่อไม่เอา; ติ๊ก *Add a title card* เพื่อได้ไตเติลตอนเปิด

## v0.2.2 — เรียง track + เอฟเฟกต์นิชเพิ่ม
1. **สลับตำแหน่ง track**: ลากไอคอน ⠿ ที่หัว track ไปวางแถวใหม่ (เส้นสีแสดงตำแหน่งที่จะตก) หรือกดปุ่ม ▲▼ — เสียงอยู่เหนือวิดีโอได้ วิดีโอลงล่างได้ ลำดับของ track วิดีโอเท่านั้นที่กำหนดว่าอะไรทับอะไร ดับเบิลคลิกชื่อเพื่อเปลี่ยนชื่อ กด × ลบ track ว่าง
2. **แท็บ Looks** (เลเยอร์ปรับสี) เพิ่ม: Anamorphic Night (แสงยาวสีฟ้าพาดทั้งเฟรม), Holo Foil (ฟอยล์รุ้ง), Handheld 1-bit (จอเกมพกพา), Amber Terminal, Camcorder (REC + timecode จริงเดินตามเวลา), Thermal Lock (ภาพความร้อน + เป้าล็อก), Kaleido Trip
3. **แท็บ Organic** เพิ่ม: Veins · Follow Edges (เส้นเลื้อยตามขอบวัตถุในภาพ), Spores · Bioluminescent (ละอองแสงลอยรับแสงจากภาพ), Cells · Glass (เซลล์กระจกหักเหภาพ), Lichen Bloom (รวมทั้งสามอย่าง)
4. เอฟเฟกต์ทั้งหมดใช้เดี่ยว ๆ ได้ในปุ่ม Effects ของคลิปใดก็ได้ และผูกกับจังหวะเพลงได้

## v0.3.0 — ตัดต่อพื้นฐาน + 3D + พรีเซ็ตขนาดใหญ่
1. **พรีเซ็ต 142 แบบ** (แท็บ *05 Presets* ฝั่งซ้าย): ค้นหาได้ (พิมพ์ vhs, chrome, beat, 3d) แยกหมวด Y2K/Street/Cinematic/Glitch/Retro/Dream/Organic/3D/Beat/Clean — ส่วนใหญ่เป็นชุดเอฟเฟกต์ 3–5 ตัวรวมกัน คลิกที่ชื่อ = ใส่ให้คลิปที่เลือกไว้ทั้งชุด (Undo ครั้งเดียวถอยหมด) กดปุ่ม **Layer** = ใส่เป็นเลเยอร์ปรับสีครอบทุกอย่างข้างใต้
2. **Reverse** (แถบ timeline): เล่นคลิปที่เลือกย้อนกลับ ทั้งภาพและเสียง — โปรแกรมจะเรนเดอร์ไฟล์ย้อนกลับเฉพาะช่วงที่ใช้ ใส่ไว้ใน Library ชื่อ "(reversed)" คลิปยาวใช้เวลาหน่อย Undo กลับเป็นคลิปเดิม
3. **Freeze** (แช่เฟรม): วาง playhead ในคลิปวิดีโอ เลือกความยาว 1/2/3/5 วินาที แล้วกด Freeze — คลิปถูกตัด ส่วนที่เหลือขยับไปข้างหลัง และมีภาพนิ่งเฟรมนั้นคั่นกลาง
4. **พลิกภาพ (Flip)** แนวนอน/แนวตั้ง ในแท็บ Inspector และเอฟเฟกต์ **Crop** (ครอปทีละด้าน มุมโค้ง ขอบนุ่ม)
5. **3D แบบที่ 1 — เอียงภาพ:** คลิปไหนก็ได้ ใน Inspector มี *3D tilt / 3D turn / 3D perspective* (ใส่ keyframe ได้) ภาพกลายเป็นแผ่นในมุมมองเพอร์สเป็กทีฟ ทำการ์ดพลิกได้
6. **3D แบบที่ 2 — วัตถุ 3 มิติ:** เอฟเฟกต์ **3D Object** (ลูกบาศก์ ทรงกลม โดนัท ฯลฯ) ห่อภาพของคุณไว้บนผิววัตถุ หรือเป็นโครเมียม กระจกใส ลวดนีออน โฮโล หมุนได้เอง ปรับตำแหน่ง/ขนาด/พื้นหลังได้ และ **Retro Grid Floor** (พื้นกริดซินธ์เวฟ + พระอาทิตย์ตก) — ลองพรีเซ็ตหมวด 3D

## v0.3.1 — คลิกลากในพรีวิว, ไทม์ไลน์แบบมืออาชีพ, เรนเดอร์เฉพาะช่วง
1. **คลิกที่ข้อความ/ภาพในหน้าจอพรีวิว** เพื่อเลือก แล้ว **ลากเพื่อเลื่อน** ได้เลย (ถ้าเลือกหลายอัน จะเลื่อนไปพร้อมกัน, ดูดเข้ากลางเฟรมอัตโนมัติ — กด Alt ค้างเพื่อปิดการดูด) ลากมุมสี่เหลี่ยมเล็ก ๆ เพื่อย่อ/ขยาย ดับเบิลคลิกข้อความเพื่อแก้คำ คลิกที่ว่างเพื่อยกเลิกการเลือก
2. **ไทม์ไลน์**: เลือกหลายคลิปด้วย Ctrl/⌘/Shift-คลิก หรือ **ลากกรอบสี่เหลี่ยม** บนพื้นที่ว่าง, Ctrl/⌘+A เลือกทั้งหมด, Esc ยกเลิก — ลากคลิปที่เลือกไว้ **ไปพร้อมกันข้าม track** ได้ มีเส้นไกด์ตอนดูดติด และเลื่อนจอให้อัตโนมัติเมื่อลากไปชนขอบ ถ้าวางแล้วจะทับคลิปอื่น ระบบจะไม่ยอมให้ทับ Undo ครั้งเดียวย้อนกลับทั้งการย้าย
3. **เรนเดอร์เฉพาะช่วง**: วาง playhead แล้วกด **I** (จุดเริ่ม) และ **O** (จุดจบ) — ช่วงที่เลือกจะแรเงาบนไม้บรรทัด ลากธง IN/OUT ปรับได้ ตอน Export จะติ๊ก "Render only the marked range" ให้เอง ไฟล์ที่ได้เริ่มจากจุด IN และเสียงถูกตัดตรงช่วงเดียวกัน กด Alt+X เพื่อล้างช่วง
